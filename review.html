Setup
  1. Google Maps Platform → a project with billing
  2. APIs & Services → enable “Map Tiles API”
  3. Keys & Credentials → the key → API restriction: Map Tiles API · Websites: this site’s address
  4. Quotas → a daily limit, so the free amount is never passed
  5. The key → above, in every browser. It stays in the browser: it is not part of the online copy or the data file.

With a key, the street map, the overlay and the bare map of the quizzes are Google’s, with English names. Without one, or when Google refuses it, they are OpenStreetMap’s. The coverage page stays on OpenStreetMap.
